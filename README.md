# Software Development OOSD

## Giới thiệu

**Software Development OOSD** là một dự án phần mềm được thiết kế với mục tiêu ứng dụng các nguyên tắc Phát triển Phần mềm Hướng Đối Tượng (Object-Oriented Software Development - OOSD). Dự án là sự kết hợp mạnh mẽ của nhiều công nghệ và ngôn ngữ lập trình hiện đại để đáp ứng các yêu cầu phát triển phần mềm phức tạp.

## Ngôn ngữ và Công nghệ được sử dụng

Dự án được xây dựng trên các ngôn ngữ và công nghệ sau:

- **Java**: Nền tảng chính để phát triển hệ thống backend hiệu suất cao.
- **TypeScript**: Sử dụng để xây dựng các tính năng frontend hiện đại và robust.
- **CSS**: Cung cấp khả năng thiết kế giao diện người dùng đẹp mắt và trực quan.
- **Other**: Một số công cụ và tài nguyên khác để hỗ trợ nâng cao chất lượng dự án.

## Tính năng chính

- **Áp dụng nguyên tắc OOSD**: Thiết kế dự án hướng đối tượng với độ mở rộng và bảo trì cao.
- **Fullstack Development**: Kết hợp giữa Java ở phía server và TypeScript ở phía client.
- **Responsive UI**: Sử dụng CSS để đảm bảo giao diện thích ứng với mọi thiết bị.
- **Khả năng mở rộng**: Cho phép tích hợp thêm công nghệ mới trong tương lai.

## Hướng dẫn bắt đầu

### Yêu cầu

Để chạy được dự án này, bạn cần:

- Cài đặt **JDK** (Java Development Kit) với phiên bản m��i nhất.
- Cài đặt **Node.js** và **npm** để quản lý các gói JavaScript.
- Một IDE phù hợp như **IntelliJ IDEA** hoặc **VSCode**.

### Cài đặt

1. **Clone repository**:

   ```bash
   git clone https://github.com/nhathuymario/software-development-oosd.git
   cd software-development-oosd
   ```

2. **Cài đặt các gói cần thiết**:

   ```bash
   npm install
   ```

3. **Build và chạy dự án**:
   - Khởi động phần backend với Java.
   - Khởi động phần frontend bằng cách chạy các lệnh cần thiết trong thư mục liên quan.

4. **Truy cập ứng dụng**:

   ```bash
   http://localhost:3000
   ```
